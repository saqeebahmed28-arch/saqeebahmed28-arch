## 🎓 About Me & Academic Journey

I am an undergraduate student pursuing **Bachelor of Engineering in Computer Science & Engineering with a specialization in Data Science (CS-DS)**.

I am passionate about learning how data can be transformed into actionable insights and intelligent systems. My focus right now is on strengthening core theoretical principles—mathematics, statistics, algorithm design, and database systems—while practicing hands-on coding and modern developer workflows.

### 🔬 What I'm Focused On Learning
- **Data Science & Analytics:** Exploring datasets with Python (Pandas, NumPy, Matplotlib, Seaborn) to uncover trends, clean real-world data, and understand statistical models.
- **Machine Learning Fundamentals:** Studying core supervised and unsupervised algorithms, feature engineering, and model evaluation metrics with Scikit-Learn.
- **Data Structures & Algorithms (DSA):** Implementing core computational building blocks in C and Python, including arrays, stacks, queues, trees, searching, and sorting algorithms.
- **Databases & SQL:** Designing relational schemas, writing analytical SQL queries, and understanding database management systems.
- **Development Tooling:** Mastering Git version control, GitHub collaboration, Linux/WSL environments, and clean coding practices.
