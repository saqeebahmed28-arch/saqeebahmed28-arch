## 🎓 About Me & Academic Journey

I am an undergraduate student pursuing **Computer Science with a specialization in Data Science (CS-DS)**. I am passionate about uncovering patterns in complex datasets, designing predictive machine learning pipelines, and building robust, scalable software architectures.

As an engineer and student, I focus on combining theoretical foundations—mathematics, statistics, and algorithm complexity—with hands-on system implementation and end-to-end software engineering.

### 🔬 What I'm Focused On
- **Data Science & Machine Learning:** Exploratory Data Analysis (EDA), statistical modeling, feature engineering, and predictive pipelines with Scikit-Learn and Python.
- **Data Warehousing & Analytics:** High-performance columnar querying (DuckDB), analytical SQL, schema design, and automated ETL/ELT pipelines.
- **Algorithms & Core Systems:** High-performance implementations in C/C++, core Data Structures & Algorithms (stacks, trees, graphs, expression parsers), and computational efficiency.
- **Full-Stack & Intelligent APIs:** Developing lightweight web APIs (FastAPI / Flask) and interactive dashboards (Streamlit) for real-time model inferencing and telemetry.

### 2. Intelligent Behavioral Health Platform

#### 🧠 **[MentalMentor](https://github.com/saqeebahmed28-arch/mentalmentor)** &mdash; *AI-Driven Behavioral Insights & Sentiment Platform*
> **Tech:** `Python` &middot; `FastAPI` &middot; `NLP / Scikit-Learn` &middot; `React` &middot; `Tailwind CSS` &middot; `SQLite`
- **Sentiment & Risk Analysis:** Real-time NLP inference engine classifying user check-ins and tracking sentiment drift over time.
- **Decoupled Architecture:** Asynchronous FastAPI backend delivering sub-50ms REST API response times for conversational scoring.
- **Privacy & Security:** Anonymized session handling ensuring user reflections remain strictly confidential and tamper-resistant.
- **Progressive UI:** Clean, responsive interface featuring emotional wellness timelines and guided intervention triggers.

---

### 3. Core Algorithms & Parsing Engines

#### ⚡ **[Algorithmic Computation & Expression Engine](https://github.com/saqeebahmed28-arch/algorithmic-engine-c)** &mdash; *High-Performance DSA Implementation*
> **Tech:** `C (C99/C11)` &middot; `Data Structures & Algorithms` &middot; `GCC` &middot; `Makefile` &middot; `Valgrind`
- **Abstract Syntax Parsing:** Fast infix-to-postfix conversion and evaluation engine built using custom stack data structures.
- **Zero Memory Leaks:** 100% leak-free dynamic memory management verified through Valgrind memory leak profiling.
- **Algorithmic Suite:** Modular implementations of graph traversals (BFS/DFS), sorting algorithms, calendar date computations, and priority queues.
- **Automated Test Harness:** Continuous CLI regression suite with edge cases covering operator precedence, parentheses mismatch, and boundary checks.

---

### 4. Machine Learning & Predictive Modeling

#### 📈 **[Customer Retention & Predictive Risk Classifier](https://github.com/saqeebahmed28-arch/predictive-risk-classifier)** &mdash; *Supervised Learning Suite*
> **Tech:** `Python` &middot; `Scikit-Learn` &middot; `XGBoost` &middot; `NumPy` &middot; `Matplotlib` &middot; `Seaborn`
- **Predictive Scoring:** Multi-model classification benchmark (Logistic Regression, Random Forest, Gradient Boosting) achieving high ROC-AUC scores.
- **Feature Engineering:** Automated missing value imputation, categorical one-hot/target encoding, and collinearity reduction.
- **Model Explainability:** Feature importance attribution and confusion matrix evaluations explaining key drivers behind churn/risk predictions.
